עדכון מערכת הטפסים – יומן עבודה יומי לקבלן
==========================================

התיקייה הזו היא עותק מלא ומעודכן של ה-repo edge-control-forms.

מה חדש:
  1. contractor_daily_log.html  – קובץ חדש. יומן עבודה יומי לקבלן תשתיות,
     כולל כתב הכמויות המלא, סימון עבודות וציוד, בחירת מי סיפק את הציוד,
     הפקת PDF ואיפוס אוטומטי של הטופס אחרי כל הפקה.
  2. index.html                 – עודכן. נוסף כרטיס לטופס החדש בקטע
     "טפסי תפעול ושירות", ליד "יומן עבודה" ו"דוח קריאת טכנאי".

כל שאר הקבצים זהים למקור ולא שונו.

איך מעלים ל-GitHub:
  - נכנסים ל-repo באתר github.com
  - Add file  ->  Upload files
  - פותחים את התיקייה הזו, בוחרים את *כל הקבצים שבתוכה* (לא את התיקייה עצמה)
    וגוררים אותם לחלון
  - Commit changes
